**Search without a candidate.** A search that leaves no candidate, for instance under a `non_box_cons` that does not always give the same answer for a point, counts as a failed search, as in MATLAB BADS; the run stopped with `UnboundLocalError` or `IndexError`. The search hedge's gains then decay, as after any failed search and as in MATLAB BADS. When a later generation of the evolution-strategy search leaves no candidate, the search keeps the candidates of the earlier generations and evaluates the best one, as in MATLAB BADS, and a debug message (`display="full"`) says that the generation left no candidate, where 1.1.0 warned that a random search was performed.
