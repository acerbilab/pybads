**Repeated points with user-specified noise.** With `specify_target_noise=True`, a point evaluated again was merged with the first earlier evaluation that shared any one of its coordinates, usually that of another point, whose value and noise it then changed. `FunctionLogger` now merges it with its own earlier evaluation, and a run no longer evaluates a point again (see "Points evaluated again"), so that no run of `BADS` merges one. On the 3-D ellipsoid above, run over 90 seeds on Linux, where 54 runs made such a merge, the fix of the merge alone lowered the median error from 0.58 to 0.48, and the number of runs with an error of 1 or more from 31 to 20.
